# Changelog

Notable changes to Musical Scraper are recorded here.

## [1.0.0] - 2026-08-25

- First public release for macOS and Windows.
- Added desktop GUI and command line interface.
- Added chronological profile scanning, resumable downloads, caption-based filenames,
  optional hashtags, date filters, and a CSV manifest.
- Added full-history cursor scanning for older posts and a watermark-free playback format
  selector.
